Ejercicio 3: Serie de Fibonacci

Enunciado

Generar la serie de Fibonacci hasta la cantidad de términos ingresada por el usuario.

Traducir el pseudocódigo proporcionado a JavaScript utilizando un ciclo for.

Cómo se resuelve

Se empieza con a = 0 y b = 1. En cada vuelta se muestra a y se actualizan los valores:

temp = a + b
a = b
b = temp

Se admiten de 1 a 78 términos para mantener valores exactos con números de JavaScript.
